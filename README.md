 VEXEL – Real-Time Multiplayer Laser Survival Game

VEXEL is a browser-based multiplayer survival game developed using Python, Flask, JavaScript, HTML, CSS, and Socket.IO. Players can create or join private rooms and compete in a laser-based survival arena.

Players secretly choose their positions and aim laser beams at opponents. Once all shots are submitted, positions and laser trajectories are revealed simultaneously. The game uses geometric collision detection to determine eliminations, while the arena gradually shrinks when no players are eliminated, increasing the challenge.

The backend manages game sessions, player states, and game logic, while Flask-SocketIO enables real-time communication between players. The frontend uses JavaScript and HTML Canvas for user interactions and game rendering.

Technologies Used: Python, Flask, Flask-SocketIO, JavaScript, HTML, CSS, HTML Canvas API.

Key Features:
- Private multiplayer rooms with unique codes.
- Real-time player communication.
- Hidden positioning and laser targeting.
- Simultaneous elimination mechanics.
- Geometric collision detection.
- Dynamic arena shrinking and round progression.
